# Công cụ cài cục bộ

Thư mục này không chứa binary hay mô hình OCR trên GitHub. Xem
[hướng dẫn cài đặt](../docs/SETUP.md).

Đường dẫn mặc định trên macOS:

- `Audiveris.app/Contents/MacOS/Audiveris`
- `tessdata_legacy/eng.traineddata` (tessdata 4.1.0, hỗ trợ legacy OCR)

Cũng có thể dùng Audiveris trong `/Applications` hoặc đặt `AUDIVERIS_BIN`.
MuseScore được tìm trong `/Applications/MuseScore 4.app` hoặc `MUSESCORE_BIN`.
`TESSDATA_PREFIX` cho phép chọn thư mục OCR riêng.
